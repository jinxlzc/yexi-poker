# 夜席 Yexi · 线下德州扑克牌桌

面对面打德州扑克，手机记虚拟筹码。电脑开本地服务，同一 Wi-Fi 的手机扫码加入。可以选择 **实体牌**（自己发牌，系统只记筹码）或 **电子牌**（系统洗牌发牌，底牌只在自己手机上，摊牌按牌力分池）。**仅娱乐积分，无充值、提现或真钱兑换。** 不计算胜率、赔率或 GTO。

> **免责声明**：夜席只记录**虚拟娱乐积分**，用于朋友之间面对面的娱乐局、学习和复盘。它没有、也永远不会有充值、提现、转账、真钱换算或「谁该付谁多少钱」的功能。请不要把它用于任何形式的赌博，并遵守你所在地的法律。

界面支持简体中文、繁體中文、English、日本語、한국어和 Español。可在页头切换语言，选择只保存在当前浏览器，不影响其他玩家；未手动选择时按浏览器语言显示，不支持的语言回退到英语。

## 安装与启动

需要 **Node.js 22.13 或以上**（用到内置的 `node:sqlite`；已在 22.13.0 和 24.22 上跑过全部单元测试），推荐 Node.js 24 LTS。不需要数据库、账号、云服务或构建步骤。

```bash
git clone https://github.com/jinxlzc/yexi-poker.git
cd yexi-poker
npm ci --omit=dev   # 只装运行时依赖（ws、qrcode）；要跑测试就去掉 --omit=dev
npm start
```

Node 22 会打印一行 `node:sqlite` 的 ExperimentalWarning，可以忽略。

依赖装好以后只需 `npm start`。无需构建、云服务、账号或外部数据库。运行时字体、页面、二维码、音效均由本机提供，不依赖 CDN。

1. 电脑浏览器打开 **http://localhost:8787**，创建房间。先选打牌方式：电子牌为预选项，可改回实体牌。默认小盲 10、大盲 20、起始 2,000、补码关闭。
2. 终端和启动页会列出电脑的局域网地址，格式为 `http://<局域网地址>:8787`。请使用你电脑实际显示的地址。
3. 手机和电脑连接同一个 Wi-Fi，扫描分享页上的真实二维码，或打开该局域网地址后输入四位房间码。选择名字和空座。
4. 至少两位玩家入座后，电脑点「新的一手」。主持人自己也玩时，同样用手机入座；主持凭证默认只保留在创建房间的电脑浏览器。
5. 玩家在自己的手机上行动。实体牌模式里，每轮下注结束停住，由电脑主持点「下一轮」。发完实体牌后按池点赢家、核对预览并确认分池。电子牌模式里，「下一轮」会发出公共牌，摊牌由系统按牌力判定。两种模式都支持在下注锁定后的全下牌局里投票选择发牌轮数，详见「本桌规则」。
6. 误操作在电脑点「撤销上一步」，二次确认后退回。分池、开手及盲注也可以撤销。撤销不会倒放动画，数字立刻回到撤销后的状态。
7. 两手之间可以在「座位」里切换打牌方式、换座、调盲注级别，并设置前注、行动计时、全下后最多发牌轮数和允许抓盲。
8. 今晚打完，主持在两手之间点 Dock 上的「散场」，二次确认。房间变成只读；每台手机自动切到自己的今晚总结，大屏显示全桌排行、时长、总手数、账平校验和高光。可以复制文字战报、保存为图片；首页「历史牌局」随时回看；「用同样设置再开一桌」一键开新桌，手机上会出现「去新桌入座」。点错了可以撤销散场。

## 一整晚会遇到的事（第四版）

- **有人先走**：手机「更多 → 离开」或主持「移出座位」。他的带入、带走、手数都记进账本，手机立刻显示他自己的今晚总结，散场排行也算他。同一台手机回来可以再入座，统计接着算。
- **暂离**：手机底部「暂离」或主持在座位页设置。下一手起不发牌、不收盲（不补盲），点「我回来了」下一手入局。
- **中途加入**：随时扫码入座，从下一手开始。
- **补码**：主持在座位页补，或玩家手机「更多 → 申请补码」，主持在牌桌上点「补码」确认（金额可改）。
- **换了手机 / 清了浏览器**：在入座页展开「之前坐过？」，选自己的名字，主持在牌桌上点「同意接回」。座位和筹码接到新手机，旧手机立即失效。名字本身不是凭证，只有主持能批准。
- **主持换人**：分享页「移交主持」给二维码，对方扫码接任。主持电脑清了缓存：在运行服务的这台电脑上用 localhost 打开首页，点「在这台电脑上接回主持」。
- **休息**：Dock「休息」。大屏显示休息时长，手机暂停，行动计时也停。
- **磨蹭 / 掉线**：可选行动计时（默认关，20–90 秒）。到时**不会自动弃牌**，只把计时环变成朱砂色；超时或掉线后主持可以「替他过牌/弃牌」（能过就过），二次确认、写进记录、可撤销。
- **涨盲和前注**可在创建时的「更多设置」或座位页调整。盲注按手数升级（倍数表 1·2·3·4·5·6·8·10…），也可两手之间手动升降一级。前注可选每人支付或由大盲支付。
- **全下跑马（Run It Twice / Thrice）**由本手还未弃牌的人各选 1、2 或 3 轮。全员完成选择后取最少轮数。主持可以选「只跑一次」直接推进，也可以替尚未选择的离线玩家代投，两者都会写进记录。
- **抓盲（Straddle）**默认关闭。主持打开后，下一手的枪口位可在两手之间勾选「下一手 Straddle」。
- **电子牌摊牌**有全下玩家时，所有未弃牌玩家都亮牌。普通摊牌时赢家自动亮牌，其他参与者可以选择「亮牌」。
- **牌谱**按街列出操作和底池，记录公开底牌、摊牌顺序以及每轮公共牌和分池。个人总结的「赢池」按手计，当手任一轮分到筹码即计一手。「最大一笔」是单手内分到的全部筹码。
- **轮到你**：手机震动（iOS 不支持）、提示音、标题栏提示；打牌时屏幕常亮（可在「更多」里关）。可以把网页加到主屏幕，下次点开直接回到房间。

手机不要访问 `localhost`，那指的是手机自己。多网卡的其他地址在启动页展开查看。没有局域网地址时不会生成假的二维码。

### 手机连不上时

- 手机和电脑必须在**同一个 Wi-Fi**。访客网络、开了「AP 隔离 / 设备隔离」的路由器、公司或酒店网络通常互相访问不了。
- 放行防火墙：
  - macOS：第一次启动时如果弹出「是否允许 node 接受传入网络连接」，选允许；或在「系统设置 → 网络 → 防火墙 → 选项」里允许 node。
  - Windows：Windows 安全中心弹窗时勾选「专用网络」并允许；或在「Windows Defender 防火墙 → 允许应用」里放行 Node.js。网络要设为「专用」而不是「公用」。
  - Linux（ufw）：把 `LAN_SUBNET` 换成你的局域网网段，再运行 `sudo ufw allow from LAN_SUBNET to any port 8787 proto tcp`。
- 电脑开了 VPN 或代理时，局域网地址可能被改写，先关掉再试。

默认监听 `0.0.0.0:8787`，只接受本机和电脑私有局域网地址作为 Host，不提供公网入口或穿透。房间只面向可信的同一局域网。请勿配置端口转发或把服务代理到公网。

可选环境变量：

```bash
PORT=8899 npm start
DATA_FILE=/绝对路径/牌桌.sqlite npm start
HOST=127.0.0.1 npm start  # 仅本机调试，手机不能访问
```

Windows PowerShell 示例：`$env:PORT=8899; npm start`。

## 局域网 http 下浏览器做不到的事

服务是局域网明文 http（浏览器不认为这是「安全上下文」），所以下面这些是**已知限制**，不是 bug：

- 不能注册 Service Worker：断网时网页不能离线打开；「加到主屏幕」只是快捷方式。
- 剪贴板 API 不可用：复制战报会退回到选中文本复制，必要时手动长按复制。
- Wake Lock 不可用：屏幕常亮退回到循环播放一个静音小视频，部分手机省电模式下仍可能锁屏。
- iOS Safari 不支持震动：轮到你时 iPhone 只有提示音和标题提示。
- 保存图片：手机上弹出图片后长按保存，电脑上下载 PNG。

没有内置 HTTPS：在局域网里给每台手机装自签证书的成本远高于收益。需要的话可以自己在前面加反向代理，但这超出本项目的支持范围（见下文「隐私与安全」）。

## 刷新、离线与恢复

- 房间、筹码、当前手、日志和最近 200 步撤销历史保存在 `data/table.sqlite`，SQLite WAL 事务提交后才广播成功。重启服务会恢复原有房间。缺少 `dealMode` 的旧房间按实体牌恢复，不会丢档。v3 及更早的房间升级后照常继续：账本按日志里的入座、补码、离开还原；旧手牌没有结构化记录，手数、入池率等从升级后的下一手开始统计，总结里会写明。
- 同一浏览器、同一访问地址保留独立的玩家凭证与主持凭证。手机刷新会恢复原座位。切换 IP、浏览器或清除站点数据会失去该浏览器的凭证，不会自动接管同名座位；需要在入座页认领，由主持确认。
- 玩家离线时保留筹码和行动位置，不会超时弃牌。轮到离线的人时，主持可以确认后替他过牌（不能过牌才弃牌），日志注明「主持代」。
- 电脑启动页的「进入牌桌（主持）」使用这个浏览器已有的凭证。凭证丢了，只有在运行服务的电脑上（localhost）能「接回主持」，其他局域网设备做不到。
- 分享页可以生成一次性主持移交链接，有效期 5 分钟。接任确认后，旧主持立即失效。同一时间只有一位主持。不要把移交链接当普通加入链接分享。
- 网络断开后手机会自动重连（指数退避，最长约半分钟一次），也可以点「立即重试」；重连后以服务器上的牌桌为准。

## 数据、备份与恢复

- 所有数据都在运行服务的电脑上：默认 `data/table.sqlite`（WAL 模式，旁边会有 `-wal`、`-shm` 文件），可以用 `DATA_FILE` 改位置。`data/` 已在 `.gitignore` 里，不会被提交。
- **备份**：先停止服务（终端里 Ctrl+C），再整个复制 `data/` 目录（或 `DATA_FILE` 指向的文件连同 `-wal`、`-shm`）。
- **恢复**：停止服务，把备份的文件放回原位置，再 `npm start`。
- **升级**：停止服务，备份 `data/`，更新代码，`npm ci --omit=dev`，再启动。旧版本的房间会自动迁移；进行中的一手最好在两手之间升级。
- **清空**：停止服务后删除 `data/`。
- 某个房间的记录损坏时，其他房间照常可用，损坏的房间会提示无法打开，原始数据保留在库里不会被覆盖。
- 请保留浏览器站点数据；数据库仅保存凭证哈希，不能从库中取回丢失的凭证。

## 本桌规则

- 支持 2–10 人，庄位与盲位按座位号顺时针轮转。零筹码和离开的座位跳过。两人局庄家下小盲，翻前先行动，翻后大盲先行动。
- 无上限德州。「加注到」是本轮总投入；最小值为本轮最高投入加上一次完整加注的幅度。跟注部分不算加注幅度。短码全下可以不足跟注或不足完整加注。
- **短码全下（Poker TDA 第 49 条）**：不足一次完整加注的全下，已经行动过的人仍要**补跟或弃牌**，但不能再加注。几次短码累计起来、相对某人上次行动达到一次完整加注幅度时，这个人恢复加注权。（4.1.0 修正了早期版本「已跟满的人不必补跟」的错误。）
- **抓盲（Straddle）**可在至少三人参与时预约。下一手枪口位（大盲左边的第一位）可自愿投入两倍当级大盲作为活盲。翻前从抓盲者左侧开始，首个完整加注至少到四倍大盲。若抓盲者筹码不足两倍大盲，按实际筹码全下，名义活盲仍为两倍大盲。交抓盲不算主动入池（VPIP）。开手时若预约者已不在枪口位，预约作废并写进记录。[Robert’s Rules of Poker，第 14 节](https://www.homepokertourney.org/roberts-rules-of-poker.htm)
- **大盲前注（Big Blind Ante）**由当手大盲支付当级设定的一份前注，与人数无关。大盲先交盲注，剩余筹码再付前注。实收前注作为死钱全部进主池，不计入当轮跟注额或边池资格。默认仍是每人支付前注。[WSOP 大盲前注说明](https://www.wsop.com/news/bigger-starting-stacks-and-big-blind-ante-coming-to-2019-wsop/)
- 每轮结束退还没人匹配的超额投入并记日志；前注是死钱，不退。底池按本手总投入分层，弃牌筹码留在池里，弃牌者没有获胜资格；相同资格的相邻层合并。
- 只剩一个人还有筹码时，他只需跟到对手实际全下的数额，不会被要求多补再退。多人变成两人局时，上一手的大盲改做庄（小盲），不会连续两手交大盲。
- **发牌轮数**上限可设 1、2 或 3，默认 3。河牌之前，所有剩余下注已经处理、至少两人未弃牌且有人全下、无法再继续下注时，才进入投票。上限设为 1 时直接发一次。只剩一人、河牌已发或仍可下注时照常推进。多发需要所有人同意，最后取全员所选的最少轮数。[Robert’s Rules of Poker，第 14 节](https://www.homepokertourney.org/roberts-rules-of-poker.htm) · [PokerStars 多轮发牌说明](https://www.pokerstars.com/help/articles/run-it-twice-new/15582/)
- **逐轮分池**时，每个主池或边池各自按轮数平分，先取整数，余数按第 1、2、3 轮顺序各加 1，直到分完。每轮从原底池有资格者中选赢家。同一轮多人并列时，按庄家左侧起顺时针给并列赢家分余数。比如 7 筹码发两轮，分成 4 和 3；第二轮并列两人时，靠庄家左侧较近的赢家得 2，另一人得 1。实体牌由主持按轮、按池点赢家。电子牌自动判定后，主持核对各轮、各池及余数去向并确认入账。[Poker TDA 分池与余数规则](https://www.pokertda.com/view-poker-tda-rules/)
- 随时加入的新玩家从下一手参与。补码、调整、移出座位只能在两手之间。补码仅主持可打开、仅允许增加，每笔留日志；离开带走的积分从全场扣除。手中申请离开后仍需自己行动，下一手开手时再移出。

### 有意不做

- **死庄／死按钮和死小盲（dead button / dead small blind）**。朋友局采用移动庄位和盲位，暂离不用补盲。多人转两人时调整庄位，避免同一人连续交大盲。
- **固定限注和底池限注（limit / pot-limit）**。夜席面向无上限德州。
- **额外思考时间（timebank）**。朋友局已有可选行动计时。需要等人时主持可暂停，超时或掉线时可代为过牌或弃牌。
- **补交错过的盲注（missed blinds）**。暂离玩家回来后从下一手入局。
- **保险（insurance）**。夜席只记录娱乐积分，无额外押注或结算。
- **追看未发的公共牌（rabbit hunting）**。下注结束后只发判定本手所需的公共牌。[Poker TDA 规则](https://www.pokertda.com/view-poker-tda-rules/)
- **炸弹底池（bomb pot）**。所有人先入池并跳过翻前下注的玩法超出普通德州流程。

## 电子牌与保密

- 一副 52 张，无大小王。洗牌使用 `node:crypto` 安全随机的 Fisher–Yates，不用 `Math.random()`。发牌从庄家左侧开始（两人局从大盲开始），每街公共牌前烧一张，烧牌不展示。
- 底牌只出现在该玩家自己的快照里。主持、看客和其他玩家在摊牌前只能看到牌背。摊牌前日志只写「已发底牌」，不写点数花色。只剩一人未弃牌时不必亮牌，池归该人。
- 多轮发牌共用已经发出的公共牌。每轮依顺序用同一牌叠补齐剩余街，每街各烧一张，各轮新牌与烧牌互不重复。摊牌按标准德州 7 选 5 判定每轮各池的赢家，主持确认自动判定的结果。
- 普通摊牌的顺序从河牌最后下注或加注的人开始；河牌无人下注时从庄家左侧第一位未弃牌玩家开始，再按顺时针轮转。普通摊牌只自动亮赢家，其他人可自选亮牌。任一未弃牌玩家全下时，所有未弃牌者都亮牌。盖掉的牌与牌型不会写入公开记录。[Poker TDA 摊牌规则](https://www.pokertda.com/view-poker-tda-rules/)

## 音效与动效

电脑总览和手机都有「音效开 / 音效关」。状态保存在 `localStorage` 键 `night-table.sound`，默认开。第一次轻触后才会发出声音。音效是本仓库原创的短 WAV（可用 `npm run sounds` 重新生成），定位是安静的私人牌局，没有背景音乐或赌场音。系统若要求减少动效，筹码不飞、牌不旋转，只用短淡入；音效仍可单独开关。

## 隐私与安全

- 数据只存在运行服务的这台电脑上，不上传、不联网、没有统计或第三方请求；页面所需字体、音效、二维码都由本机提供。
- 保存的内容：房间设置、玩家填写的名字、筹码与账本、操作日志、牌谱、凭证的哈希；电子牌模式下进行中的牌叠与底牌（为了重启后能继续这一手）。摊牌时盖掉的牌不会出现在日志、牌谱、总结或任何其他人的画面里，但仍留在本机数据库里——能读这台电脑文件的人能看到。
- 访问控制：只接受本机和本机局域网地址作为 Host（防 DNS rebinding），写操作检查同源，创建房间和接回主持只能在本机 localhost 上做；写接口和 WebSocket 每个来源有频率上限。
- **信任边界**：这是给可信局域网用的。流量是明文 http，同一网络里能抓包的人可以看到内容；知道四位房间码的人可以旁观公开信息。不要做端口转发、内网穿透或把服务暴露到公网。
- 发现安全问题请按 [SECURITY.md](SECURITY.md) 私下报告。
