# 夜席 Yexi — 产品说明

朋友面对面打德州扑克：牌是实体牌，筹码用手机里的虚拟积分。电脑在同一 WiFi 开一台本地服务，所有人用浏览器加入，一起看牌桌概览、下筹码、轮转盲位、由主持人点赢家并分配底池。

**仅娱乐积分，无充值、提现、真钱兑换。** 第一版不发虚拟牌、不算牌力；第二版增加可选的电子牌模式，由系统洗牌、发牌，并在摊牌时按牌力判定赢家。两种模式都不计算胜率、赔率，也不提供充值提现。

## 角色与设备

- **电脑（主机/公共牌桌）**：开服务，展示房间码和二维码、座位与筹码、底池与边池、当前行动人、庄/小盲/大盲、手牌与操作日志；主持人在此（或经主持权限的设备）开局、点赢家、处理分池、必要时撤销误操作。
- **手机（玩家）**：扫码或输入房间码加入；看到自己的筹码与当前可执行操作（fold / check / call / raise / all-in）及行动状态；不能替别人下注，不能执行主持专属操作（除非该设备同时是主持人）。

## 首版范围

- 2–10 人。
- 房间码 + 二维码加入。
- 主持权限：创建房间的人默认为主持人，可指定赢家、分池、撤销、开新一手、调整座位/补码（如做补码需记录日志，默认关闭随意改别人筹码）。
- 断线重连：同一玩家刷新或暂时掉线后，用房间码 + 玩家身份（稳定的玩家 token / 座位凭证，存在浏览器本地）恢复，不丢筹码与进行中的一手。
- 持久化：服务重启后能恢复房间、筹码、当前手与日志（本地文件或嵌入式数据库即可）。
- 手牌/操作日志：谁在何时 fold/check/call/raise/all-in、盲注、分池结果，可回看。
- 误操作撤销：主持人可撤销最近一次合法记录的操作（或逐步回退），撤销后积分必须重新守恒。
- 中文、移动端优先的精致界面；电脑牌桌总览也要好看、远看清晰。

## 德州流程（系统负责筹码与行动合法性，不负责牌面）

系统自动轮转庄位和大小盲，并从对应玩家筹码中扣除盲注。正确处理：

- **Heads-up（两人）**：庄家是小盲、先说话（翻前）；另一人是大盲。不要套用 3 人以上的「庄家左边是小盲」。
- **3 人及以上**：庄家左侧小盲，再左侧大盲；翻前从大盲左侧开始行动。
- **短码 all-in / 重开规则**：加注必须满足最小加注（通常为「至少再增加一个与上一次加注幅度相等的量」，补齐到跟注的部分不算加注幅度）。筹码不够跟注或不够完整加注时可以短码 all-in；短码 all-in **不重开加注权**：已经行动过的玩家仍须补跟差额或弃牌，但不能再加注，除非相对他上次行动累计出现了一次完整加注幅度（Poker TDA 第 49 条）。（4.1.0 修正：早期实现把「不重开」误解为「不必补跟」。）
- **边池（side pots）**：按投入分层，只有对该层有贡献（eligibility）的玩家才有资格分该边池。主持人点赢家时必须能按边池分别指定（含一池多个赢家平分）。
- **平分余数**：底池不能整除时，余数按约定规则分配（建议：从庄家左侧开始，按有资格的赢家顺序各得 1 个剩余筹码），必须写进规则与测试，且全场积分守恒。
- **手动点赢家 ≠ 忽略下注合法性**。fold 的人不能赢自己没有资格的池；未投入某边池的人不能分该边池；行动阶段仍要校验：轮到谁、是否可以 check、call 数额、最小加注、all-in 只能用自己剩余筹码等。
- 一手结束、分池完成后进入下一手，庄与盲位前进一格（淘汰/离开的座位要跳过）。筹码为 0 的玩家本局不能再被收盲（可保持旁观或离开）。

## 非目标（首版不做）

- 充值、提现、支付、账号体系、互联网公网暴露的默认配置。
- 保险、比赛记分牌（ICM）、胜率或赔率计算。电子牌模式下的发牌与摊牌牌力判定见下文，不延伸到这些功能。
- 跨网络复杂 NAT 穿透（首版假定同一局域网；启动说明里写明如何让手机访问电脑的局域网地址）。

## 建议的技术取向（实现者可调整，但需可在本机一键启动）

- 一台电脑启动本地服务，手机用浏览器打开 `http://<局域网IP>:<端口>`。
- 实时同步（WebSocket 或等价方案），刷新后状态一致。
- 提供清晰的启动命令、局域网访问说明，以及自动化测试（见测试要求）。

## 必须覆盖的自动化测试

1. 筹码守恒：任意合法操作序列后，所有玩家筹码 + 所有底池 = 开局（或补码后）总积分。
2. 最小加注规则。
3. 短码 all-in 不错误地重开已关闭的行动。
4. 边池 eligibility（谁有资格分哪一池）。
5. 平分与余数分配。
6. 盲位轮转，含 heads-up。
7. 重连后状态恢复。
8. 主持权限（非主持人不能点赢家/撤销/随意改筹码）。

# 第二版（双模式）

第一版只服务「有实体牌、没有筹码」的朋友局。第二版在不改局域网、娱乐积分、无充值提现的前提下，补上牌桌的现场感，并增加没有实体牌时也能完整打完一手的电子牌模式。

两种模式共用同一套筹码规则、盲位轮转、边池、平分余数、撤销、重连和主持权限。差别只在牌从哪里来、赢是谁判的。

## 打牌方式

房间在创建时选择，两手之间可以由主持切换。已有房间若没有该字段，视为实体牌，保持兼容。

| 模式 | 牌 | 推进轮次 | 点赢家 |
| --- | --- | --- | --- |
| **实体牌** | 桌上的纸牌。界面不发底牌和公共牌。 | 一轮下注结束后，主持点「下一轮」，好让大家看完已发出的实体牌。 | 主持按池点赢家，系统只校验资格与守恒。 |
| **电子牌** | 服务端用密码学随机洗牌并发牌。每人两张底牌，公共牌在翻牌、转牌、河牌发出。 | 下注轮结束后可以由主持点「下一轮」发公共牌；若已无人可再下注（例如多人全下），系统按街自动发完公共牌并进入摊牌，不必再空点。 | 系统按牌力自动判定每个池的赢家（含平分与余数规则），主持只确认分池，不能改判。 |

电子牌不是线上赌场：仍然只在同一局域网，没有账号、充值、提现或真钱兑换。

## 电子牌规则（系统负责牌面）

- 一副 52 张，无大小王。洗牌使用 `crypto` 安全随机的 Fisher–Yates，不能用 `Math.random()`。
- 发牌顺序：从庄家左侧（两人局是大盲）开始，轮流发第一张底牌，再发第二张。每街公共牌前烧一张，烧牌不展示、不进入牌力计算。
- 翻牌发 3 张，转牌、河牌各 1 张。公共牌对全桌可见。
- **底牌保密**：只有该玩家自己的快照包含自己的两张底牌。主持、看客、其他玩家的快照里只能看到「已发底牌」的牌背，直到摊牌。摊牌前日志只写「已发底牌」，不写点数花色。
- 摊牌时，仍未弃牌的玩家在公共牌桌上翻开底牌，并标注牌型名称（如「同花」「两条」）。弃牌者默认不亮牌。
- 只剩一人未弃牌时，不必亮牌，底池直接归该人，进入确认分池。
- 牌力按标准德州 7 选 5，从高到低：皇家同花顺、同花顺、四条、葫芦、同花、顺子、三条、两对、一对、高牌。A-2-3-4-5 是最小的顺子；同牌型用踢脚比较；完全相同则平分。判定必须确定性，并有固定牌例测试。
- 电子牌模式的分池预览由服务端写入，客户端只展示。确认后的入账规则与第一版完全相同，全场积分仍然守恒。

## 第二版仍然不做

- 充值、提现、支付、账号体系、默认公网暴露、端口转发或穿透。
- 胜率、赔率、GTO、保险、ICM。
- 用同名冒领座位、看别人底牌、在电子牌模式里改判赢家。
- 把仓库现在就改为公开。开源是后续事项；本版所有音效、牌面、筹码图形必须是本仓库原创，以便日后开源。

## 第四版：散场与一整晚

- **散场**：主持在两手之间点「散场」，二次确认。房间只读。每人手机弹出个人总结，大屏显示全桌排行、时长、总手数、账平校验和高光；可复制文字战报、保存图片；首页「历史牌局」可回看总结和牌谱；「用同样设置再开一桌」。不做「谁该转账给谁」，只显示娱乐积分的盈亏。
- **个人总结只放算得准的数字**：总带入（含补码）、最终筹码或带走、盈亏、名次、打了几手、拿下底池、最大一笔、入池率、全下、亮过的最好牌。旧版本打过的手不进统计，并写明。
- **提前离席**就是个人散场：同样的总结卡片，可存图；回来再入座统计接着算。
- **暂离、中途加入、换座、移出、换手机认领（主持确认）、主持移交（二维码）、本机接回主持、休息、可选行动计时（默认关，到时不自动弃牌，主持可代过牌/弃牌）、可选前注与按手数涨盲、电子牌盖牌与主动亮牌、每手牌谱、轮到你提醒、屏幕常亮、加到主屏幕**。使用说明见 [README](../README.md)「一整晚会遇到的事」。
- 原则不变：服务器不替人做决定；规则、守恒、底牌隐私、音效开关、减少动效都不回退。
