# 视觉体系

公共牌桌要在客厅里站着也能读。手机要在拇指下好按，并且经得起中文的字宽。气质是夜里一张漆过的桌子：墨绿色的暗，暖白色的字，黄铜只做标记。

不要赌场剪贴画，不要花色铺底，不要霓虹渐变，不要金币和筹码插画。积分用数字本身表达。

视觉稿的变量写在 `mockups/styles.css`，与下表同名。

## 颜色

深色是默认，也是唯一主题。不提供浅色牌桌。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#101311` | 页面底 |
| `--bg-elev` | `#171c19` | 顶栏、抬起的面板 |
| `--bg-elev-2` | `#1e2622` | 对话框、加注面板 |
| `--felt` | `#1b2420` | 桌面椭圆 |
| `--felt-deep` | `#141c19` | 椭圆外沿 |
| `--text` | `#f3f1ea` | 主文字、主要数字。暖白，不用纯白 |
| `--text-dim` | `#c5cdc8` | 辅助文字。要达到正文对比度 |
| `--text-faint` | `#8f9b96` | 仅用于 13px 以上的次要元数据，或更大的弱提示 |
| `--brass` | `#c6a15b` | 庄标记、底池描边、当前日志 |
| `--brass-2` | `#e2c78a` | 黄铜上的亮字、全下标签 |
| `--brass-ink` | `#2a210f` | 庄标记里的字 |
| `--amber` | `#e4a04a` | 行动中、主按钮、跟注额 |
| `--amber-ink` | `#1c1408` | 琥珀按钮上的字 |

| `--clay` | `#e0a090` | 弃牌文字与描边 |
| `--clay-deep` | `#c46a4a` | 撤销等真正要提交的危险确认 |
| `--pine` | `#9cb89a` | 守恒「齐」 |
| `--danger` | `#e07a66` | 权限不足、对不上账 |
| `--line` | `rgba(243,241,234,0.10)` | 发丝分割 |
| `--line-strong` | `rgba(243,241,234,0.18)` | 卡片边 |

对比度目标：关键数字和名字在桌面上至少 7:1，辅助文字至少 4.5:1。弃牌、行动、全下除了颜色，还必须有文字。

按钮填色：

- 跟注、过牌：暖白填充，深色字。这是顺着局面走的动作。
- 加注、确认分池、坐下：琥珀填充，深色字。这是改价格或定结果的动作。
- 弃牌：透明底，陶土色描边和文字。
- 全下：透明底，黄铜描边。少见，所以不做红色脉冲。
- 撤销确认：陶土深色填充。
- 不可用：透明度 0.36，去掉填充，不参与脉冲。

桌面椭圆用径向的深浅，外加一条 1px 黄铜内环和很轻的内阴影。不要木纹贴图，不要第二层彩色光晕。行动座位可以有一圈很淡的琥珀，这是整个画面里唯一的发光。

## 字体与字号

| 角色 | 字体 | 说明 |
| --- | --- | --- |
| 界面中文 | Noto Sans CJK SC | 回退苹方、微软雅黑。字重只用 400 和 700 |
| 数字 | IBM Plex Sans | `font-variant-numeric: tabular-nums`。回退 Geist，再回退界面字体 |
| 地址 | IBM Plex Mono | 只用于 URL 和端口 |

生产环境自己托管这些字体。视觉稿依赖设计机上已安装的同名家族。

中文不要加字距。房间码用 0.16em 到 0.18em 的字距，便于口播。数字千分位用英文逗号：`1,640`。不写小数，不写货币符号。

电脑牌桌，以 1440 宽为基准。1920 宽时底池加到 72px，「轮到谁」加到 40px。1280 宽时底池降到 56px，其余不变。

## 间距、圆角、阴影

间距刻度：4、8、12、16、24、32、48。

手机页左右 16。电脑页左右 20 到 24。按钮之间至少 10，弃牌和跟注之间至少 12。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-s` | 8 | 日志行 |
| `--radius-m` | 12 | 按钮、小牌 |
| 座位、手机主按钮 | 14 | |
| `--radius-l` | 16 | 面板 |
| 对话框 | 18 | |
| 标记 | 999 | 庄、小、大、人数药丸 |

阴影只用黑色透明，不带彩色：

- 座位：`0 10px 28px rgba(0,0,0,0.32)`
- 面板与手机框：`0 24px 64px rgba(0,0,0,0.40)`
- 弃牌座位去掉投影，让它退到桌面里。

## 动效

| Token | 值 | 用途 |
| --- | --- | --- |
| 微交互 | 120ms | 按下、开关 |
| 状态 | 200ms | 数字交替、边池出现 |
| 仪式 | 360ms | 庄标记移动、两手之间座位重排 |
| 行动呼吸 | 2400ms | 行动座位的琥珀环，缓入缓出，不弹跳 |
| 缓动 | `cubic-bezier(0.22, 0.8, 0.24, 1)` | 全部位移 |

`prefers-reduced-motion: reduce` 时取消呼吸和位移，状态用 80ms 的透明度交代。

数字变化：旧数字上移 8px 淡出，新数字淡入，200ms。不做老虎机滚动。

开新的一手，中央按这个顺序发生：

1. 「第 N 手」出现。
2. 庄标记沿座位环滑到下一位有筹码、且没有离开的人，360ms。
3. 小盲、大盲标记落在系统指定的人身上。两人局时，庄和小盲在同一张座位卡上并排。
4. 盲注从对应座位扣下，底池加上同样的数。守恒条两边一起变，全场那个数不动。可以有一条 1px 的黄铜细线从座位连到底池，280ms，只出现一次。
5. 行动环亮起，中央写「轮到某人」。

这条细线是账本上的一笔，不是飞出去的筹码。减少动效时不画这根线。

禁止：筹码堆飞入底池、翻牌动画、花色粒子、按钮弹跳、全下时的红闪。

## 没有实体筹码、也不发牌时，桌子靠什么

桌子中央是一叠池子，不是五张牌。

- **手的仪式**靠「第 N 手」、盲标记换人和数字同时加减。大家看得到钱进了池，也看得到是谁被收了盲。
- **行动**靠琥珀环，加上中央一句「轮到林川」。环在呼吸，字是琥珀。两到三米外先看见这个。
- **底池**是全场最大的数字，暖白，安静。它不闪。
- **边池**是底池下面的小牌。已确定的池用实线黄铜框；还在下注的池用虚线，并写「形成中」。每条写上有资格的人的名字。
- **盲位**是座位角上的圆标：庄是实心黄铜，里面一个「庄」；小盲是细线圆，里面一个「小」；大盲是略大的琥珀细线圆，里面一个「大」。标记直径 22px，大盲 24px。
- **弃牌**不打叉，也不把人变透明到读不出筹码。名字和剩余仍清晰，标签写「弃牌」，边框改成淡陶土，投影去掉。
- **全下**剩余显示 0，标签写「全下」，底边用黄铜。筹码还在池里，所以这个人的资格要能在边池条上找到。
- **离线**用虚线边和「离线」两个字。数字保持原亮度，因为筹码还在。

轮次名称用来对齐桌上的实体牌，界面里不出现牌面：翻前、翻牌圈、转牌圈、河牌圈、摊牌。

## 层次

一张桌子上同时只有三个层级：

1. 行动：琥珀，有呼吸，中央重复一次名字。
2. 底池：最大的暖白数字。边池是它的下一层，字号大约是总额的三分之一。
3. 盲位与座位：标记很小，筹码数字中等。弃牌退一层，但数字还在。

主持按钮在行动进行时全部降成不可用，避免和「轮到谁」抢注意力。唯一保持可用的主持动作是撤销，它用陶土线框，放在日志底下，不做成琥珀。

## 远看与 375 宽

电脑总览的设计宽度是 1280 到 1920。低于 1100 时，日志改到桌子下面，主持条允许换行。电话投到电视上时，仍以中央的「轮到谁」和底池为准，不依赖座位里的小字。

十人局座位卡可以收到约 132×72，名字 14px，筹码 22px。行动环和中央标题保持原尺寸。

两人局两张座位分列左右，底池居中，中央在开手时留一句「两人局 · 庄家下小盲，翻先前行动」。

手机以 375 宽设计，320 宽仍不横向滚动。操作区贴在可视区域底部，并加上 `safe-area-inset-bottom`。浏览器自己的工具栏会占掉一块，所以主按钮不要假设贴着物理屏幕底边；用 sticky 放在页面底部即可。

## 无障碍

- 焦点用 2px 黄铜描边，偏移 2px，只在 `:focus-visible` 时出现。
- 中央「轮到谁」用 `aria-live="polite"`。手机上轮到自己时用 `assertive`，文案就是「轮到你」。
- 二维码旁边始终有房间码和完整 URL。示意稿里的码不能扫描；正式产品的码必须能打开加入链接。
- 守恒条是 `role="status"`。
- 对话框打开时焦点进到「返回」，而不是危险确认。
