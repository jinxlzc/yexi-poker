# 组件规格

尺寸以 CSS 像素计。电脑基准 1440 宽，手机基准 375 宽。颜色和字号见 [visual.md](visual.md)。

## 守恒条

高度 36。居中一行：`全场 10,040 = 座位 8,590 + 池中 1,450`，末尾圆角标签「齐」。

- 三个数字用等宽数字，暖白。运算符弱化。
- 全场变化时（补码、有人带筹码离开）标签改为「含补码 +500」或「有人离开 −1,640」，全场数字一起变。
- 预览或任何展示中的分配若对不上，标签改为陶土色「对不上」，相关确认按钮不可用。
- 始终渲染，包括空房间（全场 0）。

## 座位

电脑卡默认 176×约 96，内边距 10×12，圆角 14。行动中的卡宽 190。

结构从上到下：

1. 盲标记行，右侧座位号。主持再加「· 主持」，不要另做一枚标记。
2. 名字 16/700，右侧状态词 12。
3. 剩余筹码 28。行动中 32。
4. 元信息 12：「本手 520 · 本轮 320」。没有投入时写「未投入」。

| 状态 | 边 | 状态词 | 筹码 |
| --- | --- | --- | --- |
| 等待 | 默认发丝边 | 等待 | 暖白 |
| 行动中 | 琥珀实线，2.4s 呼吸 | 行动中，琥珀 | 暖白 |
| 弃牌 | 淡陶土边，无投影 | 弃牌，陶土 | 仍可读，略弱 |
| 全下 | 黄铜边 | 全下，黄铜 | 显示 0 |
| 离线 | 虚线 | 离线 | 原亮度 |
| 旁观 | 默认边 | 旁观 | 0 |
| 下一手入座 | 不占当前椭圆 | 小条「下一手」 | 显示起始筹码 |

十人局卡可收到 132×72，名字 14，筹码 22。中央标题不缩小。

座位在总览上不是按钮。分池工作台里，有资格的人才是按钮，最小高度 72。

禁用：进行中的一手，座位不能拖动。调整只在两手之间，通过「顺时针 / 逆时针」，不使用自由拖拽。

## 筹码数字

- 整数，千分位逗号，表格数字。
- 剩余是座位上最大的数。本手、本轮比它至少小两级。
- 增减在预览里写成 `+501`，不写减号池（池用自己的总额）。
- 不出现筹码图形、小数、货币符号。

## 底池与边池

中央总额在上，字号 64。下面每条池是一块小牌：左上名称，右侧金额，下方资格人名，用间隔号分隔。

- 主池在前，然后是边池、边池 2。名称由资格从宽到窄排列。
- 连续分层如果有资格的人相同，合并成一条，金额相加。
- 下注未结束：虚线框，名称后加「形成中」。若行动的人跟注后会获得资格，用黄铜小字写「林川跟注后加入」。
- 分池时：实线。左栏可选，选中为黄铜框和 8% 黄铜底。
- 金额为 0 的池不画。

弃牌的人的筹码留在池的金额里，名字不出现在资格行。

## 庄 / 盲标记

圆，直径 22，大盲 24。可并排，间距 4。两人局允许「庄」和「小」同时出现。

| 标记 | 填充 | 字 |
| --- | --- | --- |
| 庄 | `#c6a15b` | 「庄」，`#2a210f` |
| 小 | 透明，1px `#c5cdc8` 边 | 「小」 |
| 大 | 透明，1px `#e4a04a` 边 | 「大」 |

标记只反映系统已经判定的角色。客户端不用座位几何自己重算谁是小盲。

## 行动按钮

手机操作区。按钮高 56，圆角 14，字 17/700。弃牌与跟注同一行：弃牌约 0.8 份宽，跟注约 1.25 份宽，间距 12。下注/加注、全下各占满一行，行距 10。

电脑上没有这组按钮。轮到谁，谁用自己的手机。

出现条件（仅「轮到你」，未弃牌，且本手还在行动）：

| 条件 | 弃牌 | 过牌 | 跟注 | 下注或加注 | 全下 |
| --- | --- | --- | --- | --- | --- |
| 跟注额 = 0，剩余 ≥ 大盲 | 确认后送出 | 单击 | 不出现 | 「下注」 | 确认后送出 |
| 跟注额 = 0，0 < 剩余 < 大盲 | 确认后送出 | 单击 | 不出现 | 不出现。原因：不够一个最小下注 | 「全下」，按短码说明 |
| 跟注额 > 0，剩余够跟注，也够最小加注 | 确认后送出 | 不出现 | 「跟注 N」单击 | 「加注」 | 确认后送出 |
| 跟注额 > 0，剩余够跟注，不够最小加注 | 确认后送出 | 不出现 | 「跟注 N」单击 | 不出现。原因：不够最小加注，可以跟注或全下 | 「全下」，说明其他人仍需补跟、但不重开加注权 |
| 0 < 剩余 ≤ 跟注额 | 确认后送出 | 不出现 | 不出现 | 不出现 | 「全下 N」。副文案：不足以跟注 |
| 剩余 = 0，或已全下，或已弃牌，或不是你的回合 | 整组不出现 | | | | |

不出现的按钮不要画成禁用态占位。原因只有一条，放在操作区上方，不挂在每个空位上。

填色：弃牌陶土线框，过牌或跟注暖白填充，加注或下注琥珀填充，全下黄铜线框。

送出中：整组锁住，已点的那颗保持填色并去掉文字变化以外的动画。失败则恢复，并给出原因。

## 加注控件

从行动页底部升起的面板，背景 `#1e2622`，圆角上 18。

- 标题：「加注到」或「下注到」。
- 数字：40px。左右各一颗 44×44 的步进，步进量是大盲。
- 滑杆：轨道高 4，拇指 20。范围从最小加注到，到本轮已下 + 剩余。视觉稿里的滑杆是静态的。
- 快捷四枚药丸，高约 32：最小、×2、×3、全下。低于最小的倍数不渲染。当前值对应的那枚用琥珀描边。
- 确认高 56，满宽。取消在其下，满宽线框，间距 8。
- 禁用确认：空、非整数、小于最小、大于全部剩余。说明写在数字下，按钮保持不可用外观。
- 等于全部剩余：确认文案改为「确认全下」。

打开面板不算一次行动。回合被别人改变时面板收起且不提交。

## 房间码与二维码

房间码四位，字符集 `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`。分享页 42px，字距 0.18em。顶栏 28px。

二维码：

- 正式码编码加入 URL，深色模块 `#1a211e`，底 `#f3f1ea`。
- 纠错等级 M。安静区 ≥ 4 模块。不圆角化，不在中心压标志，不反色。
- 分享页边长 ≥ 168，顶栏 44 作为入口，点开回到大码。
- 视觉稿里的 `qr.svg` 只示范底色、留白和尺寸，不能扫描。

码的旁边始终有 URL。读屏以 URL 和房间码为准。

## 权限定

三种外观，不混用按钮：

| 模式 | 看得到 | 看不到 |
| --- | --- | --- |
| 主持 | 主持条、撤销、分池工作台 | 手机那组行动按钮（即使主持人也要到自己的手机上行动） |
| 玩家 | 行动页 | 主持条、撤销、分池里的选择 |
| 看客 | 只读总览、「我要加入」 | 主持条和行动按钮 |

拒绝时用顶部提示，不改状态。提示背景 `#2a211f`，边 `rgba(224,122,102,0.45)`，可换行。约 4 秒收起。

本机启动页的「进入牌桌（主持）」只出现在回环地址。移交主持是电脑上的一次确认码，确认后旧浏览器变成看客或玩家。

## 日志列表

一行：时间 12px 弱色，正文 13（侧栏）或 15（展开）。最近一行左边 2px 黄铜，底 `rgba(198,161,91,0.08)`。

侧栏宽 300，列表自己滚动，撤销按钮钉在列表下，不跟着滚走。展开页最大宽度 720，居中。

空状态一行说明，撤销按钮不可用。

日志不提供编辑。补码、离开、代收盲、分池结果用同一行样式，靠文字区分，不另做一套彩色标签墙。

## 确认对话框

宽 420，375 宽时距边 16。背景 `#1c2420`，圆角 18，内边距 22。遮罩 `rgba(8,10,9,0.64)`。

结构：标题 22，说明 15 弱色，引用条（被撤销的动作或全下金额）圆角 12，然后两个满宽按钮，间距 10，各高 56。

| 对话框 | 安全按钮 | 提交按钮 |
| --- | --- | --- |
| 弃牌 | 返回 | 确认弃牌，深陶土填充 |
| 全下 | 返回 | 确认全下，黄铜线框。金额用 40px 数字 |
| 分池 | 返回 | 确认这样分池，琥珀填充 |
| 撤销 | 返回 | 确认撤销，`#c46a4a` 填充，深色字 |
| 离开 | 留下 | 确认离开，陶土填充。写明带走的筹码 |

安全按钮在上，也是打开后的焦点。点遮罩等于安全按钮。不提供倒计时自动确认。

## 主持条

高 76，左右 20。左侧「主持 · 阿宁 / 行动在各自手机上」。主按钮宽至少 112，高 52，主文案加一行 10px 原因。

| 按钮 | 可用 | 不可用时的小字 |
| --- | --- | --- |
| 新的一手 | 两手之间，且至少两位有筹码 | 本手进行中 / 还差一位玩家 |
| 下一轮 | 本轮行动已结束，且还没到摊牌，且还有人能在后面的轮次行动 | 还有人要行动 / 没有下一轮 |
| 分池 | 摊牌条件满足，或只剩一人未弃牌，或没人还能行动 | 还没到摊牌 |
| 座位 | 两手之间 | 本手不可调 |
| 撤销上一步 | 本手至少有一条记录 | 这一手还没有操作 |

不可用时透明度 0.36，不是琥珀。看客模式整条不渲染。

## 同桌摘要（手机）

高 44 的横滑药丸。当前行动者琥珀描边。弃牌降低透明度。每枚至少能点中但默认不可点，只是状态。375 宽大约可见 6 枚短名；更长时横向滚动，不撑破页面。
