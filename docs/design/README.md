# 牌桌 · 界面与交互设计

朋友围着一张实体牌桌打牌。电脑放在茶几上，给全屋看座位、筹码、盲注和底池。每个人用自己的手机行动。第一版的界面只记积分和谁该说话，不发牌，也不判断牌力。第二版在这个基础上增加音效、分码动画，以及可选的电子牌模式，见 [v2.md](v2.md)。

本目录是界面规格。服务端、存储和工程脚手架不在这里设计。产品规则以 `docs/PRODUCT_SPEC.md` 为准，本文只规定这些规则如何被看见、被点到、被确认。

视觉气质叫「夜席」：深色漆面、暖白文字、少量黄铜。黄铜只用在庄位、底池和形成中的边池上。

## 原则

- 远看先知道谁在行动，再知道底池有多少。盲注贴在座位上，不跟底池抢桌子中央。
- 近看先给大按钮。跟注写明金额。弃牌和全下要再确认一次。
- 数字仍是筹码的权威。第二版用陶瓷筹码堆和飞行动画把数字落到桌上；电子牌模式才会发虚拟底牌和公共牌，并在摊牌时显示牌型。两种模式都不显示胜率或赔率。
- 守恒一直挂在牌桌上：全场 = 各座位剩余 + 所有池。分池预览若对不上，确认按钮不可用。
- 下注是否合法由系统判断。界面只展示结果，不让玩家点到不合法的操作，也不替别人下注。
- 看实体牌的空档由主持人推进。一轮下注结束后，界面停住，不自动跳到下一轮。
- 无倒计时。第二版有真实牌桌向的音效（筹码、纸牌、过牌轻敲），有独立静音，不要赌场或老虎机声。
- 中文界面。房间码、URL、盲注缩写和 all-in 可以保留拉丁字符，但按钮主文案用中文。

## 信息架构

```text
本机启动页（跑服务的电脑，回环地址）
  创建房间
  进入牌桌（主持）
  本机地址、房间码、二维码

牌桌总览（主持浏览器）
  座位环、底池与边池、守恒条、本手日志
  新的一手 / 下一轮 / 分池
  座位（两手之间才能调，补码入口也在这里）
  撤销上一步

牌桌总览（看客）
  与上面同一张桌子，没有主持按钮
  「我要加入」

手机加入
  名字、空座
  我的行动页
    过牌 / 跟注 / 弃牌 / 加注 / 全下
    加注面板
    只读日志
```

玩家凭证和主持凭证分开存放在各自浏览器里。刷新后各回各的页面。

## 设备分工

| | 电脑 · 公共牌桌 | 手机 · 玩家 |
| --- | --- | --- |
| 谁在看 | 全屋，大约两到三米 | 拿着手机的那个人，一臂距离 |
| 首要信息 | 轮到谁、底池、边池资格、盲标记 | 自己还剩多少、跟注额、现在能按什么 |
| 能做的事 | 开新手、推进轮次、分池、撤销、调座位 | 只操作自己的 fold / check / call / raise / all-in |
| 不能做的事 | 不在这台电脑上替人按跟注或加注 | 不出现分池、撤销、改别人筹码 |

三种模式：

- **主持**：创建房间的那个浏览器。底部有主持条。
- **玩家**：用房间码加入并坐下的浏览器。打开行动页。
- **看客**：打开了牌桌地址，但没有坐下、也没有主持凭证。只读总览，可以去加入。

主持凭证默认留在创建房间的电脑上。主持人自己也玩牌时，用手机当玩家，走回电脑做分池和撤销。这样沙发上的误触不会把池分掉。

本机回环地址上的启动页提供「进入牌桌（主持）」，用来在同一个浏览器里恢复主持。局域网里的其他设备看不到这个入口。若要把主持交到另一台设备，电脑上生成一次性移交，对方确认后，旧设备退出主持模式。同一时间只有一个主持。

## 界面决策

这些决定不改产品规则，只规定界面怎么做。

1. 盲标记展示系统判定的角色。两人局不在界面上套用「庄家左边是小盲」。
2. 座位沿椭圆按顺时针均分。座位号 1–10 稳定。人数变化只在两手之间重排位置，当前手的画面冻住。
3. 屏幕顺时针的下一位就是「庄家左侧」。余数、行动顺序的图示都按这个方向。
4. 下注未结束时，边池可以显示，但必须标成「形成中」。同一资格集合的连续分层合并成一条。
5. 只剩一名未弃牌玩家时，池子预填给这个人，仍由主持人确认后入账。
6. 玩家离线时保留座位和筹码，不自动弃牌，主持人也不能代他行动。轮到他时，桌子明确写着在等他重连。
7. 筹码为 0 的人下一手旁观，不收盲，庄和行动都跳过他。
8. 本手进行中加入的人，从下一手才入座行动。
9. 补码默认关闭。打开之后，每一次改动写入日志，并抬高「全场」这个数。
10. 弃牌、全下、分池确认、撤销都是两步。过牌和跟注单击。
11. 加注金额是整数，单位是「加注到」（本轮总投入），旁边同时写「再投入」。
12. 平分余数：先整除，余数从庄家左侧起，只在本池被点中的赢家里顺时针每人 1 个。池比赢家少时，排在后面的人这个池是 0。
13. 有人在两手之间离开，日志写明带走的筹码，全场总额减去这笔。进行中的一手不能把人直接挪走。

## 三组独立样例

视觉稿和下面的数字都是样例。三组彼此独立，只保证每一组内部守恒。端口 `8787`、地址 `192.168.1.23`、房间码 `4F2K` 都只是示例。

**样例 A · 刚开房。** 小盲 10，大盲 20，起始 2,000，补码关闭，还没有人坐下。

**样例 B · 第 7 手翻牌圈，轮到林川。** 全场 10,040 = 座位 8,590 + 池中 1,450。

| 座位 | 人 | 标记 | 状态 | 剩余 | 本手 | 本轮 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 周可 | 庄 | 弃牌 | 2,000 | 0 | 0 |
| 2 | 何麦 | 小盲 | 弃牌 | 1,990 | 10 | 0 |
| 3 | 小满 | 大盲 | 等待 | 1,480 | 520 | 320 |
| 4 | 老陈 | | 全下 | 0 | 200 | 0 |
| 5 | 阿宁 | 主持 | 等待 | 1,480 | 520 | 320 |
| 6 | 林川 | | 行动中 | 1,640 | 200 | 0 |

底池 1,450。主池 810，有资格的是小满、老陈、阿宁、林川。边池 640 形成中，目前只有小满和阿宁投入；林川跟注后加入。林川跟注额 320，最小加注到 640。

**样例 C · 第 8 手摊牌。** 全场仍用 10,040 教学。分池前座位合计 8,839，池中 1,201。主池 1,001 由阿宁、林川平分，余 1 给阿宁（庄是周可，从他左侧数到的第一位赢家）。边池 200 给林川一人。阿宁 +501，林川 +700。

## 实现时不要从界面里长出的东西

不画底牌和公共牌，不算牌，不显示 outs。不放倒计时。不在玩家手机上放主持按钮。不因为离线或超时自动弃牌。不把「下一轮」做成自动跳转。不发明充值、账号或公网入口。
