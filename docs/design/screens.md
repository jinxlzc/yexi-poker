# 逐屏说明

状态用词在各屏里复用：空、等待、轮到你、等待他人、结算中、一手结束。电脑是公共画面，没有「轮到你」，对应的是「轮到某人」。

样例数字见 [README.md](README.md)。按钮是否出现以 [components.md](components.md) 为准。

## 启动与分享（电脑）

**目的：** 让同桌的人找到这张桌子。

**主要元素：**

- 本机回环地址上的说明：服务开在这台电脑。
- 主局域网地址，以及收起的「其他地址」。
- 创建字段：房间名、小盲、大盲、起始筹码、补码开关。
- 创建之后：房间码、二维码、URL、规则摘要、空座说明、「进入牌桌（主持）」。

**状态：**

| 状态 | 画面 |
| --- | --- |
| 空 | 还没有房间。只有创建字段和地址 |
| 等待 | 房间已在，还没有两位玩家。二维码是主体，「还没有人坐下」 |
| 一手结束 / 已开局 | 这一页退居次要。顶栏仍留房间码。主画面是牌桌 |

**关键文案：** 「手机和这台电脑连同一个 Wi-Fi。」「至少两位有筹码的玩家坐下后，才能开新的一手。」

**无障碍与 375：** 这页主要给电脑。若在 375 宽打开，地址、房间码、二维码上下排列，二维码不小于 168px，URL 可以换行。二维码的替代文本就是旁边的 URL。创建字段的标签在输入框上方，不用占位符代替标签。错误写在字段下面，不只靠红框。

视觉稿：`mockups/join.html` 左侧。

## 加入（手机）

**目的：** 用名字坐到一个空位上，拿到这台设备的玩家凭证。

**主要元素：** 房间名，盲注摘要，房间码（扫码进入时已填），名字输入，空座选择，主按钮「坐到 N 号位」。

**状态：**

| 状态 | 画面 |
| --- | --- |
| 空 | 房间码错误或还没填名字。主按钮不可用 |
| 等待 | 本手进行中。可以占座，说明从下一手开始 |
| 轮到你 | 不在这一页。坐下成功就离开 |
| 等待他人 | 两手之间坐下后，若还没开手，进入行动页的等待 |
| 结算中 | 允许占座，明确不参与正在分的池 |
| 一手结束 | 正常坐下，等待主持人开下一手 |

**关键文案：** 「1–8 个字。这个房间里不能重名。」「起始筹码 2,000，由房间决定。你不能自己改数字。」「若本手已开始，你会从下一手才进入行动。」

**无障碍与 375：** 单列，左右 16。座位选择每格高度至少 48。名字框字号不小于 16，避免 iOS 聚焦时放大整页。主按钮高度 56，贴在底部 sticky。320 宽时三个座位格仍可点，字不溢出。

视觉稿：`mockups/join.html` 右侧。

## 电脑总览

**目的：** 全屋共用的一张桌子。两米外能看出谁在行动、谁弃了、池有多大、谁有资格。

**主要元素：**

- 顶栏：牌桌、房间名、房间码、小二维码、地址、第几手、轮次、主持是否在这台电脑。
- 守恒条：全场 = 座位 + 池中，以及「齐」。
- 椭圆桌面。中央是轮到谁、能力一句、底池总额、主池和边池。
- 座位卡环绕桌沿：座位号、盲标记、名字、状态、剩余、本手与本轮。
- 右侧本手日志，底部「撤销上一步」。
- 主持条：新的一手、下一轮、分池、座位。看客没有这条。

**状态：**

| 状态 | 中央 | 主持条 |
| --- | --- | --- |
| 空 | 「把房间码给同桌的人」 | 新的一手不可用 |
| 等待 | 已有人，还差开局条件或等人坐下。「还差一位有筹码的玩家」 | 条件满足后，新的一手可用 |
| 轮到某人 | 琥珀「轮到林川」，加上跟注或可过牌 | 新的一手、下一轮、分池都不可用，各写原因 |
| 等待他人 | 公共画面没有这个词。没轮到的人看手机 | 同上一行 |
| 本轮结束 | 「这一轮结束 · 请看牌」 | 下一轮可用 |
| 结算中 | 工作台替换椭圆，见分池屏 | 确认这样分池 |
| 一手结束 | 「这一手结束」池中为 0 | 新的一手是主按钮 |
| 有人离线且轮到他 | 「林川不在线。筹码还在，这一手停在他这里」 | 不出现代弃牌 |

**关键文案：** 「轮到 林川」「跟注 320 · 可以加注或全下」「边池 · 形成中」「林川跟注后加入」「行动在各自手机上」。

**无障碍与 375：** 总览不是为 375 设计的。375 打开时改成单列：先中央行动和底池，再座位列表，再日志。不维持椭圆，避免字小到不可读。行动状态不靠颜色单独表达。电脑宽度低于 1100 时日志移到桌下。焦点顺序：顶栏、守恒条、当前行动标题、日志、主持条。

视觉稿：`mockups/table.html`，样例 B。

## 手机行动页

**目的：** 只让当前玩家做自己的动作，并看得清跟注额。

**主要元素：**

- 顶：房间码、第几手、轮次。
- 自己的名字和剩余，本手已投入，全场总额。
- 信息板：底池、跟注额、最小加注到。
- 一条同桌摘要，可横向滑动，不抢按钮的位置。
- 底部操作区，或一块「等待」状态板。

**状态：**

| 状态 | 操作区 |
| --- | --- |
| 空 | 还没坐下时不进入此页 |
| 等待 | 「下一手你就坐下」或「等主持人开新的一手」。没有行动按钮 |
| 轮到你 | 按矩阵显示弃牌、过牌或跟注、下注或加注、全下 |
| 等待他人 | 「轮到 林川」。写自己这一轮已做的事。没有按钮 |
| 结算中 | 「主持人正在分池，请看电脑。」若预览里已有你的数字，加一行「预览里你是 +700」 |
| 一手结束 | 「这一手结束。」剩余用大字。没有行动按钮 |
| 已弃牌 | 「你已弃牌，等这一手结束。」 |
| 已全下 | 「你已全下，等这一手结束。」 |
| 旁观 | 「筹码是 0，下一手不收你的盲。」 |
| 重连中 | 「正在恢复你的座位。」成功后回到上面对应的状态 |

**关键文案：** 「跟注 320」「弃牌和全下会再确认一次」「还没到你。这一轮你已经下注 320。」

**无障碍与 375：** 操作区在第一屏里，375×667 不需要滚动才能按到跟注。按钮高 56，全宽或并排时弃牌略窄、跟注略宽，间距 12。左右 16。同桌摘要高度约 44，超出横向滚，页面本身不横向滚。底部预留安全区。轮到你时标题对屏幕阅读器 assertive。等待态不放禁用按钮。

视觉稿：`mockups/phone.html` 前两台。

## 加注面板（手机）

**目的：** 把「加注到」定成一个整数再送出。

**主要元素：** 当前跟注额和最小加注到，大号整数，减、加，滑杆，最小 / ×2 / ×3 / 全下，确认与取消。

**状态：**

| 状态 | 确认按钮 |
| --- | --- |
| 轮到你，金额合法 | 「确认加注到 960」或「确认下注到 …」 |
| 金额为空、低于最小、含小数 | 不可用，说明写在数字下方 |
| 金额等于全部剩余 | 文案改为「确认全下」 |
| 等待他人 | 面板不存在。回合结束时若还开着，直接收起，不送出 |

**关键文案：** 「加注不会在打开面板时送出」「再投入 960」。

**无障碍与 375：** 面板从底部升起，占屏幕下半，上面仍能看见自己的剩余。减和加的热区 44×44。滑杆另有数字框，不强迫只用滑杆。取消是完整的一行按钮。打开后面板外的桌面区域点一下等于取消。

视觉稿：`mockups/phone.html` 第三台。

## 主持人分池（电脑）

**目的：** 按池指定一人或多人，在确认前看清余数和守恒。

**主要元素：**

- 守恒条改为「分池前全场 = 座位 + 池中」，并写预览后全场是否仍相等。
- 左：每个池的金额、是否已指定、资格摘要。当前池用黄铜框。
- 中：当前池有资格的人，大按钮。选中写「平分」或「独得」。下面是不能选的人及原因。
- 右：余数说明、每人增减、分出合计、分池后全场。
- 底：「返回牌桌」和「确认这样分池」。确认后再出对话框。

**状态：**

| 状态 | 画面 |
| --- | --- |
| 结算中 | 工作台。未指定完时确认不可用 |
| 只剩一人 | 赢家已预填，其他人因弃牌不可选 |
| 一手结束 | 离开工作台，回到总览的结束态 |
| 等待 / 轮到某人 | 不进入此页。分池按钮不可用 |

**关键文案：** 「点一人独得，点多人即平分。」「主池 1,001 由 2 人平分，每人 500，余 1。庄是周可，从他左侧数起，第一位赢家是阿宁，这 1 个给阿宁。」「分池后全场仍是 10,040。」

**无障碍与 375：** 工作台在 375 宽改成上下堆叠：池列表、赢家、预览、确认。确认按钮 sticky 在底部。赢家按钮高度至少 72，名字 18px。不能选的人不是按钮，读屏能读到原因。预览在每次选择后更新，`aria-live="polite"`。

视觉稿：`mockups/settle.html`，样例 C。

## 日志与撤销

**目的：** 回看这一手谁在何时做了什么，并让主持人撤销最近一步。

**主要元素：** 时间、动作、最近一条黄铜左边线。侧栏是压缩版，展开页是完整版。撤销只挂在最近一条上。

**状态：**

| 状态 | 日志 |
| --- | --- |
| 空 | 「这一手还没有操作。」撤销不可用 |
| 等待 / 轮到某人 / 等待他人 | 持续追加。盲注、下注、弃牌、进入下一轮都在里面 |
| 结算中 | 追加「进入分池」。确认前的点选不记入，确认后记每个池的结果 |
| 一手结束 | 保留上一手，直到新的一手开始后改记新手。展开页可以翻之前的手 |

每条至少包含：时刻、谁、动作、金额。盲注写「小盲 10」。短码全下写「全下 150 · 短码」。分池写每个赢家拿到的数，包括余数给了谁。补码和离开单独成行，因为它们改变全场总额。

**关键文案：** 「撤销上一步？」「只会撤回最近这一条。」「确认撤销」。

**无障碍与 375：** 展开页单列，时间列 56px。对话框在 375 宽距边 16，按钮上下排列、各高 56。焦点先到「返回」。侧栏在窄屏移到牌桌下方，撤销按钮仍紧挨最近一条。

视觉稿：`mockups/log.html`。

## 权限不足（反馈，不是独立工作台）

**目的：** 拒绝得明白，并且不改变牌局。

**主要元素：** 一条贴在页面上方的提示。没有主持按钮的空壳。

**状态：** 任何状态下都可能出现，出现时不切换牌局状态。

**关键文案：** 「没有主持权限。分池、撤销和开新一手只在主持那台电脑上。」

**无障碍与 375：** 用 `role="status"`。宽度不超过内容区，375 下左右 16，可换行。不挡底部行动按钮；若空间不够，行动按钮优先，提示收在顶栏下一行。

视觉稿：`mockups/phone.html` 标题下的那一条。
