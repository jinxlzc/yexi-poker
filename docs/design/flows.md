# 关键流程

行动按钮的显示矩阵在 [components.md](components.md)。这里写人怎么一步步走过。文案原文在 [copy.md](copy.md)。

术语：

- **剩余**：还能再投入的筹码。
- **本手**：这一手已经投入的总额。
- **本轮**：这一轮下注已经投入的数额。
- **跟注额**：补齐到本轮最高下注还要再付的数。为 0 就可以过牌。
- **最小加注到**：本轮已有下注时，等于「本轮最高 + 上一次完整加注幅度」。只把跟注补齐，不算一次加注。本轮还没有人下注时，最小下注额是大盲，按钮写「下注」。

## 1. 启动，看见本机地址

跑服务的电脑打开本机页面。

1. 页面先写「牌桌开在这台电脑上」。
2. 列出手机可以打开的地址，主地址是局域网 IPv4，格式为 `http://<局域网地址>:8787`。有多块网卡时，主地址用局域网私有地址，其余收在「其他地址」里。
3. 同一页提供「创建房间」。已经有房间时，改成「进入牌桌（主持）」和现成的房间码。
4. 页脚说明：手机和这台电脑连同一个 Wi-Fi。公网地址打不开。

失败：一个可用地址都没有。文案「还没有局域网地址。确认电脑已连上 Wi-Fi，然后刷新。」不给一个假的二维码。

## 2. 创建房间

主持在本机页面填写：

| 字段 | 规则 | 默认 |
| --- | --- | --- |
| 房间名 | 1–16 个字 | 今晚的牌局 |
| 小盲 | 正整数 | 10 |
| 大盲 | 整数，且 ≥ 小盲 | 20 |
| 起始筹码 | 整数，且 ≥ 大盲 | 2,000 |
| 补码 | 开关 | 关闭 |
| 人数 | 不预选座位数 | 来了再坐，最多 10 |

提交后进入分享态，并记下这个浏览器的主持凭证。起始筹码旁可以提示「家用局常常是大盲的 100 倍」，不因此拦截。

大盲小于小盲，或起始筹码小于大盲：字段下用一句话说明，提交按钮不可用。

## 3. 展示房间码和二维码

分享态同时出现三样东西：

- 四位房间码，字号很大，字距拉开，方便念。字符集去掉 `0 O 1 I`。
- 二维码，浅底深色模块，安静区至少 4 个模块，分享页上不小于 168px。内容是 `http://<主地址>/join?room=<房间码>`。码中不放标志。
- 完整 URL 文本，摄像头不好用时可以手打。

顶栏在整局期间保留缩小的房间码、小二维码和主机地址。看客和玩家都能看到码，方便后来的人加入。

## 4. 手机加入

1. 扫码或打开地址，房间码已填好。手打进入时先输入房间码。
2. 房间不存在：「没有这个房间码。」
3. 输入名字，1–8 个字，去掉首尾空格。重名：「已经有人叫这个名字。换一个，大家才分得清。」
4. 选择空座。默认选中号最小的空座。起始筹码由房间决定，玩家不能改。
5. 点「坐到 N 号位」。
6. 浏览器保存玩家凭证。进入行动页。

本手已经开始：可以占座，状态是「下一手入座」。这一手不收盲，不进行动，也不出现在当前资格里。电脑座位环在这一手不重排，只用一张小条写「某某人 · 下一手」。

两手之间加入：立刻坐上，下一手若剩余大于 0 就参与。

## 5. 补位

补位就是上面的加入，加上主持人在「座位」里看到的结果。

- 空座在加入页上可以点。电脑总览不把 10 个空椅子都画出来；有人要来时，分享页和加入页能看到空位。
- 主持人不能把别人拖进座位。每个人用自己的手机坐。
- 两手之间，主持人可以让座位顺时针或逆时针挪一格，用来换谁坐在谁旁边。进行中的一手里，这个控件不可用，说明「这一手结束再调」。

## 6. 开手，收盲

条件：至少两名剩余筹码大于 0、且已经入座的玩家。否则「新的一手」不可用，说明「至少两位有筹码的玩家坐下后才能开始。」

主持人点「新的一手」：

1. 按视觉体系里的顺序移动庄、落下盲、更新数字。
2. 筹码为 0、已离开、或还在「下一手入座」的人跳过。庄、小盲、大盲和第一个行动的人都按跳过之后的顺序决定。
3. 日志写下开手、庄是谁、每个盲是多少。
4. 行动环落在第一个该说话的人身上。

三人及以上：庄的顺时针下一位是小盲，再下一位是大盲。翻前从大盲的下一位开始。

两人：庄家同时是小盲，翻前庄家先说话，另一人是大盲。界面把「庄」和「小」标在同一个人身上，并在中央放一句两人局说明。这句话留到这一手第一次行动结束，不做成要人关掉的对话框。

盲注大于剩余时，按实际剩余全下收盲，日志写明数额。这是系统入账，不是玩家按的全下。

## 7. 轮到自己

手机在轮到该玩家时：

- 标题区用 assertive 现场读出「轮到你」。
- 剩余筹码用最大字号。
- 信息板同时给出底池、跟注额、最小加注到。跟注额为 0 时，第三格改成「可以过牌」。
- 操作区出现，规则见组件矩阵。
- 电脑中央写成「轮到某某人」，并写一句能力说明，例如「跟注 320 · 可以加注或全下」。

不是你的回合：手机不渲染行动按钮，改成一块状态板，「轮到某某人」，加上你自己这一轮已经做了什么。

## 8. 行动按钮与防误触

玩家只能在自己的回合提交。提交在途时，整组按钮锁住，直到桌上状态更新或明确失败。

- **弃牌**：点一下打开确认。「确认弃牌？这一手你不能再赢任何池。」返回在上，确认在下。确认后按钮区换成「你已弃牌，等这一手结束。」
- **过牌**：仅跟注额为 0 时出现。单击即送出。
- **跟注**：写明金额，例如「跟注 320」。单击。它和弃牌隔开，并且是浅色填充，弃牌是线框。
- **下注 / 加注**：点一下只打开面板，不送出。关面板或点取消，牌局不变。
- **全下**：点一下打开确认。确认里用大号数字重复剩余筹码。若这笔钱够一次完整加注，写「还在手里的人还要行动」。若不够，写「已经跟满并且本轮行动已关闭的人，不会被重新打开。」

过牌和跟注成功后，手机顶部短句「已过牌」或「已跟注 320」，大约 1.2 秒。玩家自己不能撤销，文案不写「点此撤销」。

失败（已经不是你的回合、金额不合法、断线）：按钮恢复，并说明原因。不显示一个看起来成功的动画。

## 9. 加注到一个整数

面板标题是「加注到」或「下注到」。

- 数字框只接受整数。空着、低于最小、或高于「本轮已下 + 剩余」时，「确认」不可用。
- 减、加按大盲步进，不越过最小和全部剩余。
- 滑杆从最小加注到一直到全部剩余，落点是整数。
- 快捷：最小、×2、×3、全下。×2、×3 指本轮最高的 2 倍、3 倍；低于最小时这个快捷不出现。
- 面板始终重复：跟注额、最小加注到、再投入多少。
- 金额等于全部剩余时，确认按钮改成「确认全下」，并带上短码或完整加注的那句说明。

短码全下不进这个面板，走全下确认。面板只服务能够达到最小加注的人。

## 10. 短码全下：要补跟，但不重开加注权

> 4.1.0 起改为标准无上限规则（Poker TDA 第 49 条）。之前版本让已跟满的人「不必再说话」并退回短码超出部分，这不符合通行规则。

有人全下但没有构成一次完整加注时：

- 电脑中央加一句「短码全下，仍需补跟或弃牌；不足完整幅度不重开加注权。」
- 本轮已经行动过的座位，行动环会回到他们身上，但只有「跟注 / 弃牌」，没有加注和全下加注。
- 日志写「全下 150 · 短码」。
- 若几次短码累计起来，相对某人上次行动已经达到一次完整加注的幅度，或之后出现一次完整的合法加注，这个人恢复加注权。

## 11. 一轮结束，进入下一轮

本轮所有该行动的人都已结束：

- 中央改成「这一轮结束 · 请看牌」。
- 「下一轮」变为可用。进行中它是不可用的，说明「还有人要行动」。
- 主持人不点，界面就停在这里。大家发实体牌。
- 点下之后，轮次名称前进：翻前 → 翻牌圈 → 转牌圈 → 河牌圈。日志记一行「进入翻牌圈」。本轮已下清零，底池保留。行动从庄家左侧第一位还能说话的人开始。

河牌圈下注结束后，「下一轮」不再出现，改为提示进入分池。

所有仍在手里的人都已全下、没有人还能行动：不提供空转的下一轮。中央写「没有人还能行动。实体牌发完后分池。」「分池」可用。

## 12. 只剩一人，确认收池

其他人都已弃牌：

- 分池页只剩实际有筹码的池，赢家预填那个还在手里的人。
- 弃牌的人全部不可选，原因是「已弃牌」。
- 主持人可以先撤销刚才的弃牌，再回来。
- 确认后池归该玩家，守恒条保持全场不变，池中变为 0。

## 13. 主持人按池点赢家

摊牌，或上一节的收池。电脑进入分池工作台，全屋都看得懂。

1. 左侧列出主池和各个边池。有筹码的池都要指定赢家。
2. 点一个池，中间只显示这个池里**有资格**的人。点一人是独得，再点其他人就是平分。再点一次取消。
3. 没有资格的人放在下面，不是按钮。原因只写「已弃牌」或「未投入这个池」。
4. 右侧预览每个人的增减。0 也列出来，用更弱的颜色。
5. 有余数时，预览顶部写清：池的数额、人数、每人整除得到多少、余数几个、按庄家左侧数到谁、余数给了谁。顺序写成「阿宁 → 林川」。
6. 余数规则：每个赢家先拿 `floor(池 / 人数)`。余下的筹码从庄家顺时针的下一位开始找，只在**本池被点中的赢家**里数，每人再拿 1 个，直到发完。池比赢家人数少时，排到后面的赢家这个池是 0，预览照实写 +0。
7. 预览上方的守恒：分出的合计等于池的合计，分池后全场等于分池前全场。对不上时确认不可用。
8. 每个有筹码的池都已指定至少一人，确认才可用。
9. 点「确认这样分池」后再问一次。对话框重复余数那一句和「全场仍是 N」。返回在上。
10. 确认后座位加上对应数字，池中归零，状态变为「这一手结束」。主按钮是「新的一手」。

边池在下注过程中可以是「形成中」。进入分池时全部变成确定的池，不再用虚线。

## 14. 撤销

主持人在日志底部点「撤销上一步」。

1. 对话框点名最近一条，例如「阿宁 · 跟注 320」。
2. 说明筹码和底池会按这一步之前重算，全场总额不变。
3. 返回在上，确认撤销在下，确认是陶土色填充。
4. 成功后日志去掉这一条，座位和池回到那一步之前，短句「已撤销：阿宁 跟注 320」。守恒条仍显示「齐」。

要回到更早，就再撤一次。不能跳着撤中间某一条。分池之后的撤销会回到分池未确认之前的状态。

开新的一手也是一条记录。撤销它会回到上一手结束、还没开新手的时候。对话框把这件事说完整：「将撤销开新一手，盲注会退回。」

玩家手机上没有撤销。

## 15. 断线重连

玩家凭证在浏览器本地。主持凭证分开存。

掉线时：

- 电脑该座位改为虚线边和「离线」。剩余筹码不动，不改成弃牌。
- 若正好轮到这个人，中央写「林川不在线。筹码还在，这一手停在他这里。连上之后可以继续。」
- 不倒计时，不自动弃牌，主持条也不提供代操作。其他人只能等，或由主持人逐步撤销。

重连：

1. 同一浏览器打开房间地址。
2. 有凭证：不经过起名，短句「正在恢复你的座位。」然后进入行动页。「已接回。你是林川，剩余 1,640。」若轮到他，直接是行动按钮。
3. 凭证还在但房间已经没了：「这张桌子不在了。」
4. 没有凭证：「这台设备没有保存过座位。用名字重新加入，或请还坐在原位的人把手机找回来。」重新加入是一个新座位，不自动吞并旧座位。旧座位继续显示离线，直到主持人在两手之间把那个空座位清掉。进行中的一手不能清掉还持有筹码或还在池里的离线座位。

刷新就是同一次重连。进行中的一手、已投入和日志都还在。

## 16. 权限不足

玩家或看客的界面不渲染主持按钮，所以正常走不到。若请求被拒绝，或看客打开了分池地址：

- 顶部一条：「没有主持权限。分池、撤销和开新一手只在主持那台电脑上。」
- 牌局状态不动。
- 这条大约 4 秒后收起，也可以点掉。不使用要把人困住的全屏错误。

看客想操作时，页面给他「我要加入」，不给他一组灰色的主持按钮。

## 17. 调整座位与补码

「座位」只在两手之间可用。

- 点一名玩家，再点「顺时针」或「逆时针」。空号也占逻辑座位，画面在这时重排。
- 日志记「座位调整：林川顺时针一格」。
- 进行中点开会看到原因，不会进入调整状态。

补码默认关闭。关闭时，座位面板写「补码关着。打开后，每次加筹码都会写入日志。」打开是房间级开关，只在两手之间可改。

打开后，每个座位有一个整数金额。「给阿宁补 500」写入日志，该座位剩余增加，守恒条的「全场」增加，并注明「含补码 +500」。玩家不能给自己补。补码不是负号，不能用它扣筹码；扣错了走撤销。

## 18. 离开

本手进行中，离开不会立刻把人从池里拿掉。按钮是「这一手结束后离开」。掉线同样不自动弃牌。

两手之间离开：座位空出，下一手跳过。剩余筹码不再计入在座合计；若需要把分兑现，那是桌上的事，界面只在日志记「林川离开，带走 1,640」，全场总额减去这笔。离开前问一句金额，避免一声不响少一截积分。

## 19. 一手结束到下一手

分池确认后：

- 中央写「这一手结束」。
- 守恒条池中为 0，全场不变。
- 「新的一手」成为琥珀主按钮。
- 筹码为 0 的人标签改为「旁观」。下一手不给他们盲，也不给他们行动。
- 庄在下一次开手时才移动，不在分池动画里提前跳。
