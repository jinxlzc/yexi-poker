# 关键中文文案

语气短、直接、不用感叹号。动作用「弃牌、过牌、跟注、下注、加注、全下」。不把「梭哈」当按钮。不写「恭喜」。金额用千分位，句子里直接放数字。

下表的「N、名字、轮次」用真实值替换。

## 状态词

座位和药丸上只用这些词，不另造同义词：等待、行动中、弃牌、全下、离线、旁观、下一手。

按钮主文案只用：弃牌、过牌、跟注、下注、加注、全下、新的一手、下一轮、分池、座位、撤销上一步、确认、返回、取消。
