# 夜席 · 第三版视觉方向

> 状态：设计稿 + 高保真静态预览（`design-preview/`），尚未落地到 `public/`。规则、服务端和测试不受本文件影响。
> 预览截图：用 `node design-preview/tools/shoot.mjs <输出目录>` 生成（默认 `design-preview/out/`，不进 git）（桌面 1440×900 @2x，手机 390×844 @3x）。v2 现状截图在同目录 `before/`。

第二版把功能补齐了，但看上去像一个「后台表单 + 一张椭圆」，离可以开源展示还差得远。第三版不再给旧界面补特效，而是从比例、材质、字体和层级重新做一遍。目标只有一句：**像一张真的、很贵的私人牌桌，而界面安静得像 Apple 的系统应用。**

## 1. 对 v2 的审视（截图见 `before/`）

## 2. 气质与关键词

夜里、私宅、漆面木桌、陶瓷筹码、纸牌。克制、温暖、有分量。

- 参照水准：Balatro 的**卡牌手感**（厚度、光、跟手的倾斜）——只学质感，不用任何它的美术、字体、牌背或小丑；高端扑克 App 的**桌面构图**（座位环绕、下注落在桌面上）；Apple 系统应用的**精致度**（统一圆角、细线、留白、玻璃材质、动效克制）。
- 不要：赌场霓虹、金币雨、闪烁 Jackpot、拟物木纹铺满屏幕、emoji 花色、卡通角色。

| `--gold` `--gold-hi` `--gold-lo` | `#e3c48a` `#f4dfb3` `#a9864f` | 香槟金：行动者、主按钮、选中态、黄铜桌沿 |
| `--seal` | `#d4573e` | 朱砂印章「夜」，品牌唯一的红 |

| `--felt-hi/felt/felt-lo` | `#175045` `#0f3b32` `#07211c` | 墨玉毡：中心一束暖光，四周收暗 |
| `--paper` | `#f8f3e8` | 牌面纸色 |
| `--red-ink` / `--black-ink` | `#c33a2c` / `#16181b` | 牌面红黑 |

材质规则：

- **毡面**：径向渐变 + SVG `feTurbulence` 噪点（`soft-light` 混合，透明度 ≤0.55）+ 一圈 1px 暖白 7% 的「印刷线」；桌面淡印「夜 席」。
- **桌沿**：黑漆（上亮下暗的线性渐变）+ 内侧一道 1px 黄铜细线（金 42%）。不用木纹贴图。
- **玻璃**：Dock、结算条、手机行动面板用 `rgba(20,25,24,.72–.98)` + `backdrop-filter: blur(20px)` + 1px 细线 + 顶部 1px 高光。
- 对比度：正文 `--text` 在 `--ink-2` 上约 15:1；`--text-2` ≥ 7:1；`--text-3`（52%）约 5:1，满足 WCAG AA 小字；毡面上的街名等装饰文字另行控制在 ≥50%。主按钮深字 `#1d1408` 在金底上 ≥ 9:1。

## 6. 组件规格

**座位**：头像 64px 圆形（同桌色相 + 首字宋体），外圈 3px 墨色 + 1px 细线；名牌 ≥136×76，圆角 14，上 13px 名字（66%），中 21px 筹码，下一条 11.5px 状态带（等待 / 下注 120 / 已弃牌）。
- 行动中：名牌金色 1px 描边 + 4px 金 10% 光晕，状态带变成金底深字「思考中 · 18 秒」，头像外 76px 计时环（2.5px，金，带 6px 辉光）。
- 弃牌：头像与名牌 42% 不透明度，不再画牌。
- 全下：筹码位置写宋体「全下」。
- 底牌：电子牌时在头像后方扇形露出两张 40px 牌背（±9°）；摊牌时换成 46px 正面并完全露出在头像上方。
- 赢家：名牌和头像金色描边 + 柔光，状态带金底写牌型（「葫芦 · K 带 10」），名牌右侧金色胶囊「+930」。

**卡牌**（宽 w，比例 1:1.4，圆角 0.085w）：纸色双层渐变 + 纤维噪点（multiply 0.35）；阴影 `0 0.16w 0.3w -0.06w rgba(0,0,0,.55)` + 2px 接触影。左上点数 Fraunces 0.42w，下方小花色 0.22w；右下大花色 0.5w；A 的大花色居中 0.58w；J/Q/K 加 0.05w 内缩金线框、淡金斜光和竖排「侍 / 后 / 王」。牌背：深墨渐变 + 双向 45° 细线纹（金 9%）+ 金框 + 中央朱砂「夜」章。摊牌时组成最佳牌型的公共牌上浮 8px 并加金色描边光，其余 55% 透明并下沉。

**筹码**：面额 1 / 5 / 25 / 100 / 500 / 1000 → 象牙 `#e9e2d0`、朱红 `#b2443a`、墨绿 `#2f7a5c`、墨黑 `#23272b`、紫 `#6d4b8c`、琥珀 `#c99a45`。顶面椭圆（高 0.5w）带 6 块镶片、内圈细线、中心微亮；侧面 3.4px 一片，带齿边条纹。按面额拆成最多 3 列、每列最多 7 片。

**底池**：黑 28% 胶囊，左侧筹码堆，「底池」12px 字距 0.12em，金额 22px；有边池时变成两张池卡，主池金色描边，标注「→ 赢家」。

**按钮**：高 52（手机 56），圆角 16–18。主按钮香槟金渐变 + 顶部高光 + 金色投影，深字；次按钮白 6% + 细线；危险操作（弃牌）只用珊瑚色描边和字；禁用 38% 不透明度。同一屏只允许一个主按钮。

**主持 Dock**：底部居中玻璃条，圆角 22，内含 46px 按钮；左组流程（新的一手 / 下一轮 / 分池），右组次级（撤销 / 座位 / 记录），中间 1px 分隔。分池时 Dock 换成结算条：标题「系统已按牌力判定」+ 每个池去向 + 「分池后全场 12,000 · 无余数」+ 返回 / 确认分池。

**手机操作面板**（390×844）：
1. 顶栏 60：印章 + 房间名 / 手数·街·盲注 + 音效。
2. 同桌条：5 个 38px 头像，下方名字和当前下注，庄位小圆片。
3. 小桌 122px：毡面圆角 26 卡片，左上「底池 450」，右上街名，五张 52px 公共牌。
4. 自己的底牌：两张 118px 大牌，±7° 扇形、底部同心；下方宋体牌型胶囊「三条 K」+ 筹码。
5. 行动面板（底部抽屉，圆角 30）：「轮到你」+ 跟注额/最小加注 + 倒计时；3px 金色计时条；「加注到」32px 金额 + −/+ 步进；滑杆（金色填充、象牙色拇指）；四个预设（最小 / ½ 池 / 满池 / 全下）；三按钮网格 0.8 : 1 : 1.35（弃牌 / 跟注 / 加注到 X）。整屏不滚动，主按钮在拇指区。

**创建房间**：左侧品牌区（112px「夜席」渐变宋体、副标、说明、Wi‑Fi 地址胶囊、左下角牌桌静物）；右侧 560 宽表单卡居中。打牌方式两张大卡并排，电子牌默认选中（金描边 + 对勾）；盲注是两个步进器；起始筹码三段（50/100/200 BB，100 BB 标「推荐」）；补码是开关行；底部一个全宽主按钮 + 「仅娱乐积分」小字。

## 7. 动效原则

- **物体在动，界面不动**：只有牌和筹码会飞；面板、按钮不弹跳、不缩放。
- 时长：牌飞行 420–520ms，翻面 360ms（过半换面），筹码入池 400ms 带 20–40ms 错落，分池按池依次 1.2–2s；UI 淡入 160ms。缓动统一 `cubic-bezier(.2,.8,.2,1)`。
- 计时环和计时条匀速走；最后 5 秒变朱砂色，不闪烁。
- 赢家：池中筹码沿弧线飞向赢家（截图里的虚线弧表示路径），落地后名牌「+930」胶囊淡入，数字滚动到新值。
- 鼠标在牌上：最多倾斜 8°，箔光跟随（透明度 ≤0.25）；手机长按自己的牌可「看牌」轻抬。
- `prefers-reduced-motion`：取消飞行、倾斜、扫光，只保留 120ms 淡入；音效独立开关。

## 9. 落地范围（下一步，需另行确认）

只动前端外观与客户端交互，不改规则、不改 `server/engine.js`/`store.js`：

1. `public/styles.css`、`public/app.css` 按本文件重写 token 与布局（预计替换约 1,000 行）；`public/cards/`、`public/chips/` 换成新花色路径、大角标牌面、陶瓷筹码。
2. `public/app.js` 的桌面、座位、手机、创建、分池模板改成新结构：座位跑道定位、名牌状态带、Dock、结算条直接在牌桌上确认分池、手机加注改为面板内滑杆（保留「确认加注到 X」的二次确认语义）。

4. 手机上的「三条 K」提示需要客户端用自己的两张底牌 + 公共牌算牌型（可复用 `server/cards.js` 的求值逻辑做前端副本），只显示给本人。
